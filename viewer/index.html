The viewer cannot run from file://: browsers block ES modules and binary data there. From the repo root run python -m http.server -d viewer 8000 and open http://localhost:8000/.

لا يعمل العارض عبر file:// لأن المتصفحات تمنع وحدات ES والبيانات الثنائية هناك. من جذر المستودع نفّذ python -m http.server -d viewer 8000 ثم افتح http://localhost:8000/.
