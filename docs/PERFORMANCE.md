## Reading this honestly

- Planning is dominated by the O(n^3) Hungarian assignment (scipy `linear_sum_assignment`) at large n. Replacing it by a sparse or nearest neighbour assignment would change plans and was not done.
- Verification is dominated by companion matrix eigenvalue solves for piece pairs whose whole leg boxes overlap. The number of such pairs grows close to quadratically because long synchronous legs have boxes that span much of the formation.
- A time splitting prefilter (cut long pieces into short sub-pieces so boxes stay small) was tried. It reproduced the same minimum separation to about 1e-13 m but was slower in a quick local trial because the per piece Python loop in candidate generation grew, so it was discarded and no result file was kept for it. A vectorised candidate search is the open next step.
- A fix that changed correctness behaviour was made earlier: a local refinement at multiple roots (`docs/VERIFIER.md`), which does not change scaling.
- Memory is not the limit at these sizes for the verifier. The Monte Carlo stress simulator was measured separately (`results/stress_scaling.json`, per trial CPU time).
