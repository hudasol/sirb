### F. Differential report

The degenerate_collision family differs between platforms: Linux with Python 3.13.16 and 3.13.0 agree on every seed; Windows (Python 3.13.0) differs on 81 of 250 seeds, 7 of them in the disagreement records. With the same numpy version, eigenvalues are not identical and matrix products identical between the builds, so the cause is the LAPACK eigenvalue routine of the numpy wheel (the companion matrix root finder), not the Python build and not Sirb code (`results/platform_probe/`).
Linux rerun of the full report against the phase 5 copy, which was made on another machine with the same Python, numpy and scipy versions: 302 changed values in 685 compared (timing fields excluded), all in the degenerate collision records and the largest gaps of that family; counts, verdict counts and the brute force check are identical. The Linux run of this machine is now the committed reference, and a second run reproduced it exactly.
