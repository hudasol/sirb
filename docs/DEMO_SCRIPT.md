# Demo video script (about 75 s)

Screen: the viewer, default show "Oryx and orb (500 drones)". Voice-over in English; repeat with the
Arabic toggle for an Arabic cut.

| Time | On screen | Voice-over |
|---|---|---|
| 0-8 s | Title, the SIMULATION ONLY banner | "Sirb turns shape sequences into drone-show trajectories, then tries to break them. It is a simulation tool, not flight-certified." |
| 8-22 s | Press Play at 4x; both views move together | "Left: the nominal plan, which passed the specified separation check. Right: the same show with 6 m/s wind and degraded GNSS. Same timeline, same camera." |
| 22-35 s | Toggle "By separation" | "Colour shows nearest-neighbour distance against the 2 metre threshold. Red means below it." |
| 35-50 s | Scroll to verification record; hover the min-separation figure, click through to Methods | "The minimum separation is computed exactly, by solving polynomial roots, and re-checked. Every number links to how it was computed." |
| 50-62 s | Switch scenario to motor failures | "Failures: two motors out, falling drones highlighted. Results here come from assumed models, not flight data." |
| 62-75 s | Toggle Arabic, RTL layout; end on Methods "sim-to-real gap" | "English and Arabic. Real shows need an operator safety case and approval from the UAE aviation authorities. Sirb helps you test the plan; it does not approve it." |
